# 과학전람회 제목 수집 도구 v0.3 — Windows

## 기존 60건에서 이어서 수집

1. 기존 수집 도구 폴더 전체를 복사해 백업하세요.
2. 새 ZIP을 풀고 내용물을 기존 `START.bat`가 있는 폴더에 덮어쓰세요. **기존 output 폴더는 삭제하지 않습니다.** ZIP에는 output 폴더가 없습니다.
3. **START_ALL.bat**를 두 번 클릭하세요. 서울을 먼저 끝낸 뒤 전국을 수집합니다. 이전에 완료한 페이지는 건너뜁니다.
4. 로그에 페이지 번호, 전체 페이지 수, 진행률이 표시됩니다. 출력 파일은 output에 저장됩니다.

Python 3.10 이상이 필요하며 추가 패키지는 없습니다. 처음 설치한다면 https://www.python.org/downloads/windows/ 에서 설치하며 Add python.exe to PATH를 선택하세요. ZIP 내부에서 실행하지 말고 모두 압축을 푸세요.

`START.bat`는 여전히 각 3페이지 시험 수집입니다. **전체 수집은 START_ALL.bat**입니다.

## 전체 수집 범위와 예상 시간

매 실행마다 첫 페이지에서 전체 건수와 마지막 페이지를 확인합니다. 이를 확인하지 못하면 무작정 페이지를 늘리지 않고 중단합니다. 제공받은 HTML 기준 전국 21,313건·2,132페이지, 서울 733건·74페이지이지만 실제 실행 시 달라질 수 있습니다. 전국 숫자는 지도논문 등을 포함한 게시판 항목 수이지 학생 수상작 수가 아닙니다.

기본 요청 간격은 최소 3초입니다. 위 규모라면 요청 간격만으로 전국 약 107분, 서울 약 4분이며 서버 응답과 파일 저장 시간까지 더 걸립니다. 사이트 robots.txt가 더 긴 간격을 요구하면 이를 따릅니다. 원본 보고서는 다운로드하지 않고 목록만 수집합니다.

수집 중 PC가 절전 상태에 들어가지 않도록 하세요. Ctrl+C로 중단하면 체크포인트와 결과를 저장합니다. 창을 강제로 닫아도 성공한 페이지의 state.json은 남지만 CSV는 마지막 체크포인트보다 늦을 수 있습니다. 재실행 또는 EXPORT_ONLY.bat로 최신 상태를 출력하세요.

새 게시물이 추가되어 첫 페이지나 전체 건수가 기존 실행과 달라졌다면, 이전 결과는 보존하고 별도 폴더에서 새로 수집하도록 중단합니다. 목록이 수집 도중 변경될 수 있어 전체 수집 후 원래 건수와 저장 건수도 비교합니다. 건수가 다르면 로그에 오류를 남깁니다.

## 분류 결과

모든 목록은 CSV(엑셀용)와 JSON(개발용)을 제공합니다.

| 이름 | 내용 |
| --- | --- |
| awards | 모든 항목을 포함하는 원본 통합 목록 |
| guidance_papers | 지도논문만 |
| projects | 지도논문을 제외한 목록. 학생 여부 미확인·교원 자료도 포함될 수 있음 |
| student_projects | 목록에 학생이라고 명시된 항목만 |
| unclassified | 지도논문 또는 학생 작품으로 확정하지 못한 나머지 항목 |
| summary.json | 분류별 건수와 수집 시 확인한 사이트 전체 건수 |
| state.json | 게시물과 페이지 재개 정보 — 삭제하거나 직접 수정하지 마세요 |
| collector.log | 진행·오류 내역 |

사용자 확인에 따라 전국의 미분류는 학생으로 분류합니다. 원래 값은 raw_record_type, 분류 근거는 classification_basis에 보관합니다. 지도논문과 다른 지역 분류는 유지합니다. 기존 state.json도 EXPORT_ONLY.bat 또는 재실행 시 이 기준을 적용합니다. 제목·수상 구분은 원문 그대로 보존합니다. 출품작 전체가 수상작이라고 단정하지 않습니다. 동일 연구가 지역/전국에 함께 등장하는 문제는 별도 검토가 필요하며, 현재 중복 방지는 출처+게시물 ID 기준입니다.

매 페이지는 state.json에 저장하고, CSV·JSON 묶음은 10페이지마다 및 완료·오류·Ctrl+C 시 갱신합니다. 기존 데이터만 분류하려면 **EXPORT_ONLY.bat**를 실행하세요. 인터넷 접속 없이 작동합니다.

## CSV가 엑셀에서 열려 있을 때

기본 CSV를 교체할 수 없으면 `awards_latest.csv`처럼 `_latest` 파일로 저장하고 수집을 계속합니다. 두 파일이 모두 열려 있으면 JSON과 state를 저장하고 경고합니다. 엑셀을 닫은 뒤 EXPORT_ONLY.bat를 실행하면 기본 CSV를 갱신합니다. 오래된 `_latest` 파일과 기본 파일을 혼동하지 말고 로그의 경로를 확인하세요.

## 다른 지역 자료

사이트별 화면과 첨부자료 구조가 달라 추가 지역 크롤러는 주소와 실제 자료를 확인한 뒤 구현해야 합니다. **현재 자동 수집이 구현된 곳은 전국·서울입니다.** 주소만 바꾼다고 다른 지역에 적용되는 것은 아닙니다.

경기도: GYEONGGI_RESULTS.url을 열면 앞서 확인한 2026년 결과 게시물로 이동합니다. 첨부 PDF를 내려받아 분석 자료로 제공할 수 있습니다. PDF에서 작품별 행을 자동 추출하는 기능은 아직 포함하지 않았습니다.

검증·정리된 다른 지역 제목 목록은 `regional-template.csv` 형식으로 합칠 수 있습니다. 템플릿에는 실제 자료나 예시 행이 들어 있지 않습니다.

- source: 경기, 부산 등 출처 이름 (전국·서울은 자동 수집용으로 예약)
- id: 해당 출처에서 변하지 않는 고유 번호. 목록 파일이라면 게시물번호-행번호처럼 출처를 구분할 수 있는 ID
- title, year: 원문 제목과 4자리 연도
- field, award: 분야와 수상 구분. 확인되지 않으면 비워두세요
- record_type: 학생 여부가 명시되면 학생, 지도논문이면 지도논문, 나머지는 미분류 또는 원문의 교원 등 구분
- url: 실제 확인한 자료 출처 URL

필수 항목은 source/id/title/year/url입니다. CSV를 편집한 뒤 UTF-8 CSV로 저장하세요. 프로그램 폴더에서 터미널을 열고 다음 명령을 실행합니다.

```powershell
py -3 collector.py --import-csv "C:\Users\사용자\Downloads\경기목록.csv"
```

잘못된 행이 있으면 전체 가져오기를 중단하며, 같은 출처+ID로 다시 가져오면 기존 행을 갱신합니다. 이 기능은 PDF를 자동으로 읽거나 다른 지역 홈페이지를 자동 방문하는 기능이 아닙니다.

## 저장된 HTML 가져오기 / 실행 옵션

```powershell
py -3 collector.py --site national --html "C:\Users\사용자\Downloads\전국페이지.html"
py -3 collector.py --site seoul --all
py -3 collector.py --site national --pages 30
py -3 collector.py --all --output output-new
py -3 collector.py --export-only
```

--pages 30은 1~30페이지라는 뜻이며 완료한 페이지는 건너뜁니다. HTML 가져오기는 파일에 들어 있는 행만 저장하고 온라인 수집 완료 표시를 하지 않습니다.

## 오류와 제한

- 페이지 번호 불일치, 반복 목록, 열 구조 변경, 잘못된 연도는 오류로 중단합니다.
- 추출 실패 HTML은 output/diagnostics에 저장합니다. 오류가 나면 최신 collector.log와 해당 HTML을 제공하세요.
- robots.txt에서 금지됐거나 허용 여부를 확인하지 못하면 수집하지 않습니다. 접근 차단과 인증서 검증을 우회하지 않습니다. 사이트의 자료 이용 조건도 확인하세요.
- 두 프로그램을 같은 output 폴더에 동시에 실행하지 마세요.
- 이름·학교명은 추출 결과에 포함하지 않으며, 제목만으로 표절이나 실험 방법의 중복을 확정할 수 없습니다.
- 수집 결과를 GitHub나 웹앱에 자동 업로드하지 않습니다.

## 검증

실제 저장 HTML과 전국 원본 응답을 이용한 추출, 자동 페이지 수 확인, 분류, 재개, 실패 응답 저장, CSV 잠금 대체 저장, 지역 CSV 가져오기를 검사했습니다. 전체 게시판을 끝까지 실시간으로 수집한 검증과 Windows 직접 실행 검증은 아직 하지 않았습니다.

```powershell
py -3 -m unittest discover -s tests -v
```

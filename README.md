# 탐구의 씨앗

학생 과학 탐구 프로젝트의 프런트엔드 프로토타입입니다. 프레임워크나 외부 패키지 설치 없이 실행합니다.

## 실행

```sh
cd /workspace/jlh
npm start
```

Python 3와 Node.js가 필요합니다. 포트 3000에서 정적 파일을 제공합니다.

## 검증

```sh
npm test
```

## 구현 범위

프로필 및 텍스트/TXT 아이디어 입력, 예시 평가와 상위 3개 후보 선택, 공통 실험 계획, 선행 연구 메모, 실험 과정·결과 기록, JSON 내보내기. 데이터는 현재 브라우저 localStorage에 저장되며 서버에 전송되지 않습니다. 브라우저 데이터 삭제 시 기록도 사라집니다. 공동 사용 기기에서는 별명을 권장합니다.

점수는 고정 예시이며 AI 평가가 아닙니다. 실험 계획은 공통 템플릿입니다. AI 의미 검색, 출처 기반 선행 연구, 주제별 계획·비용·구매처, AI 분석, DOCX/HWP 지원, 인증, 보고서 출력은 미구현입니다. model.mjs를 실제 평가 서비스와 연결할 수 있습니다.

각 클라우드 작업은 격리되어 있으므로 기존 체크아웃을 사용하며, 요청 없이 별도 Git worktree를 만들지 않습니다. 환경 게시 또는 원격 배포는 수행하지 않습니다.

## 실제 제목 검색

입력/후보 화면에서 서울·전국 수집 목록 3,053건을 검색할 수 있습니다. 기본 검색에서 지도논문 863건을 제외합니다. 전국 미분류 1,457건은 사용자 확인에 따라 학생으로 분류하고 원본 값과 근거를 유지했습니다. 서울 원본 유형이 화학/물리인 4건은 확인 필요로 보존합니다. 전체 게시판 수집 완료를 의미하지 않습니다.

search.mjs는 공백·기호를 정규화하고 제목 구절 및 2글자 조각의 겹침을 비교합니다. 임베딩·AI·본문 중복 판정이 아니며 네 항목 평가 점수에는 반영하지 않습니다. 데이터 갱신: python3 tools/prepare_awards.py 입력.json data/awards.json

## OpenAI 평가 연결 (개발 단계)

`npm run dev:ai`는 루프백 전용 Python 서버(8000)를 실행합니다. API 키는 보안 환경 변수 LLM_API_KEY로 전달하며 브라우저에 넣지 않습니다. 후보 화면의 AI 평가는 서버 연결과 키가 있을 때 활성화됩니다. 실제 모델 호출은 별도의 OpenAI 과금 대상입니다.

네 항목 평가·근거·검증된 참고 출처를 저장하고 평균/PASS/상위3을 코드로 계산합니다. API 키 미등록 시 평가 준비 중으로 표시하며 예시 점수를 실제 AI 결과로 바꾸지 않습니다. 생성 및 실험 설계 AI 도구는 아직 연결 전입니다. GitHub Pages에서는 이 서버를 실행할 수 없습니다. 상세 실행·색인 생성·공개 배포 전제는 backend/README.md를 참고하세요.

## 공개 AI 서버 배포 준비

Render용 render.yaml과 Gunicorn 기반 시험 서버, 접근 코드/서명 쿠키, SQLite 지속형 요청 제한을 추가했습니다. 화면과 API를 같은 Render 주소로 제공합니다. [배포 안내](docs/RENDER_DEPLOY.md)를 따라 계정 연결·비밀 값 입력·비용 검토 후 배포할 수 있습니다. 공개 서버가 실제 생성되었다는 의미는 아닙니다.

## 기능명세 기반 순차 개발 (로컬 작업 브랜치)

- 원본 명세: [docs/FUNCTIONAL_SPEC_v1.1.md](docs/FUNCTIONAL_SPEC_v1.1.md)
- 구현 비교·순서·직접 확인법: [docs/SPEC_GAP_ANALYSIS.md](docs/SPEC_GAP_ANALYSIS.md)
- 사용자 결정: 원본 주제 최대 20개. 첫 작업은 선생님 기본값/학생 조건/문서 가져오기·확인/원본 ID/기존 기록 보존입니다.
- 실행: `python3 -m backend.server --port 8012` (Windows는 `py -3 -m backend.server --port 8012`). 정적 서버의 TXT 입력은 가능하지만 DOCX/HWPX/HWP는 이 로컬 Python 서버가 필요합니다.
- HWP는 hwp5txt가 설치된 환경에서만 시도하며 미설치/실패 시 HWPX·DOCX·TXT 변환을 안내합니다. OCR은 제외합니다.
- 실제 AI는 아직 기존 4항목 평가입니다. 5항목 가중 평가와 관심사/중복검사/생성/실험설계는 다음 순차 작업입니다. 이 브랜치의 공개 배포는 진행하지 않습니다.

## 2단계: Find_Interest (로컬)

원본 목록 확정 후 관심사를 직접 작성하거나 AI 분류 초안을 요청할 수 있습니다. 서버가 근거 ID를 검증하고 주제 수/비율을 계산하며 교사가 수정·확정하면 실제 평가에 연결합니다. 직접 분류는 API 비용이 없고, AI 분류는 비용 확인 후에만 호출합니다. 이전 분류/평가를 보존하고 변경 시 재검토 처리합니다. [계약·저장·검증 안내](docs/FIND_INTEREST.md)를 참고하세요. 기존 네 항목 평가 및 공개 사이트는 유지합니다.

## 선생님이 개발본을 직접 테스트하기

Windows에서는 개발 브랜치 ZIP을 풀고 **START_LOCAL.bat**를 두 번 클릭하면 브라우저가 열립니다. 수집 도구용 Python 3.10 이상을 재사용하며 Node.js/Git 설치는 필요하지 않습니다. 이 실행 파일은 유료 API 키를 전달하지 않아 직접 관심사 분류·파일 입력·제목 검색·기록을 비용 없이 확인할 수 있습니다. 최신 개발본 다운로드·업데이트와 기록 보존 방법은 [테스트 안내](docs/TESTING_FOR_TEACHERS.md)에 정리했습니다.
